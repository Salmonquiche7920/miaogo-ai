# 苗準出發 MiaoGo AI

手機優先的苗栗 1～3 日短旅規劃 Web App。以「2027 台灣燈會」為使用者自訂的固定時間節點，先確認行程**走得完、接得上、資料有來源**，再考慮偏好，並把順路的在地餐飲、合法旅宿、文化體驗與地方服務放進行程。

> ⚠️ 本專案為黑客松展示版。內建資料皆為**示範資料**，不代表即時資訊、官方確認、實際空房或實際價格。燈會展期、場域、停車與接駁目前都標示為「待確認」。

---

## 快速開始

需求：Node.js 20 以上（開發時使用 Node 22）。

```bash
npm install
npm run build
npm start          # http://localhost:3000
# 開發模式：npm run dev
```

不需要任何 API 金鑰即可完整操作；缺金鑰時各服務會自動改用明確標示的降級方案。

### 測試

```bash
npm run lint       # TypeScript 型別檢查
npm test           # 單元測試（Vitest，29 項）
npm run test:e2e   # 瀏覽器端對端測試（Playwright，360×740 手機視窗，8 項）
```

端對端測試會自動啟動（或沿用已啟動的）`npm start`，截圖存在 `test-results/screens/`。

## 評審示範情境（可重現）

在「規劃」第一步點選「快速示範情境」，會帶入條件並跳到確認頁，再按「產生行程」：

| 情境 | 展示重點 |
|---|---|
| 台南家庭自駕 2天1夜 | 計畫書範例；第 1 天 19:00 賞燈、燈會後入住、隔天退房依返程方向安排 |
| 台北情侶高鐵 1 日遊 | 大眾運輸只排入可抵達的地點；賞燈後由高鐵苗栗站返程 |
| 台中朋友自駕 3天2夜 | 第 2 天賞燈；鎖定「南庄老街」為必去項目（不可替換） |
| 衝突示範：趕不上燈會 | 指出抵達太晚、返程時間不足的原因與可修改項目 |
| 衝突示範：民宿最晚入住 | 已訂民宿 21:00 前入住但賞燈到 21:30，提示修改方向 |

產生行程後可試：

1. **行程頁**：依日切換時間軸；燈會固定時間有醒目標示；每段顯示移動時間與緩衝。
2. **左滑或「換一個」**：替換一般景點／餐飲，系統先檢查營業、移動、燈會、住宿、返程才替換，並提供「復原」；燈會、鎖定、已完成項目不可替換。
3. **☔ 雨備方案／🔄 旅途中重新規劃**：輸入目前時間（例如 16:30 模擬延誤）、位置、已完成項目與原因 → 顯示變更原因與前後差異 → 確認後才採用，可復原。
4. **探索頁**：依行程或「我現在附近」排序（不依熱門度），可篩選類型、鄉鎮、室內；「加入行程」前會重新檢查，不合適會說明原因。
5. **設定頁**：「背景主題預覽」可切換 4 種天氣 × 4 個時段；「降低動畫效果」、字體大小、定位與資料使用說明、清除本機資料、問題回報。

## 系統架構

```
使用者條件 → 有來源的候選資料 → 固定限制檢查 → 彈性條件排序 → 可行候選行程
          → AI 文字整理（逐項驗證，失敗降級）→ 最終驗證 → 時間軸與地圖輸出
```

| 目錄 | 說明 |
|---|---|
| `src/lib/engine/core.ts` | 時間重算（retime）、最終驗證（validate）、候選評分 |
| `src/lib/engine/planner.ts` | 前置衝突檢查、每日區域、旅宿挑選、填入行程 |
| `src/lib/engine/ops.ts` | 換一個、從探索加入、雨備與旅途中重新規劃（共用同一套檢查） |
| `src/lib/adapters/` | **介接層**：`places`（資料）、`travel`（交通／地圖時間）、`weather`（天氣）、`ai`（生成式 AI） |
| `src/lib/data/places.ts` | 苗栗示範資料（含來源、更新日期、確認狀態） |
| `src/config/lantern.json` | 燈會可更新設定（展期、場域、點燈、停車、接駁） |
| `src/lib/theme.ts` | 天氣 × 時段背景主題設定 |
| `src/app/api/*` | 伺服器端 API：`plan`、`swap`、`insert`、`replan`、`places`、`weather`、`status`、`feedback` |
| `src/components/` | 四個分頁與共用元件 |

**規劃規則重點**

- 固定限制（不得違反）：燈會時間、已預約活動、營業時間、必要移動與緩衝、旅宿入住／最晚入住／退房、返程時間。
- 燈會前預留停車／步行（自駕 30 分）或接駁（大眾運輸 20 分）緩衝，數值可在 `lantern.json` 調整。
- 彈性條件（排序用）：偏好、同行對象、預算、順路程度（繞路分鐘）、每日區域、在地服務、推薦分散（以種子產生小幅差異，不凌駕可行性）。
- AI 只改寫推薦理由、注意事項與每日摘要；輸出後檢查是否出現行程外地點、行程中沒有的時間、價格、聯絡方式或「即時／空房／官方已確認」等字眼，不通過者改用規則式文字。
- 重新規劃採「最小變動」：先判斷只縮短停留能否解決，不行才取消一站（優先取消較晚的景點），被取消的景點會嘗試移到後續日期。

## 環境變數

複製 `.env.example` 為 `.env.local`。**所有金鑰只在伺服器端讀取**（沒有 `NEXT_PUBLIC_` 前綴），不會出現在前端程式；`.env*` 已列入 `.gitignore`。`/api/status` 只回報各服務是否啟用，不回傳金鑰。

| 變數 | 預設 | 說明 |
|---|---|---|
| `ANTHROPIC_API_KEY` | （空） | 啟用 Claude 整理行程文字；空白則使用規則式文字 |
| `AI_MODEL` | `claude-opus-5-5` | AI 模型；已啟用伺服器端拒答備援（fallbacks） |
| `AI_DISABLED` | `false` | 設為 `true` 可強制使用規則式文字 |
| `WEATHER_PROVIDER` | `auto` | `auto`／`cwa`／`open-meteo`／`none` |
| `CWA_API_KEY` | （空） | 中央氣象署開放資料授權碼（F-C0032-001） |
| `TRAVEL_PROVIDER` | `demo` | `demo`（距離估算）或 `google` |
| `GOOGLE_MAPS_API_KEY` | （空） | Google Distance Matrix，用於校正已排定路段 |
| `MAP_PROVIDER` | `osm` | `osm`（OpenStreetMap 圖磚）或 `none`（內建路線示意圖） |
| `MAP_TILE_URL` | OSM 官方圖磚 | 可換成自架或付費圖磚服務 |
| `DATA_PROVIDER` | `demo` | `demo` 或 `tdx` |
| `TDX_CLIENT_ID`／`TDX_CLIENT_SECRET` | （空） | 交通部 TDX 觀光景點 API |

## 資料來源與示範資料標記

| 類別 | 目前 | 正式版建議來源 |
|---|---|---|
| 景點、文化場館 | 公開可查的苗栗知名地點，座標為近似值，營業時間為示範值（標「可能變動／待確認」） | 交通部觀光署觀光資訊資料庫、TDX 觀光 API、苗栗縣政府 |
| 在地餐飲 | 以「鄉鎮商圈／店家群」呈現，**不虛構特定店家** | 業者公開資訊、合作店家確認 |
| 合法旅宿 | 區域示範佔位，入住規定為示範值 | 交通部觀光署旅宿網、使用者實際預訂資訊 |
| 地方服務 | 兩筆標明「示範佔位」的青創店家／導覽 | 合作業者提供並確認 |
| 燈會 | `src/config/lantern.json`，全部「待確認」 | 官方公告後更新該檔並把 `status` 改為 `confirmed` |
| 天氣 | Open-Meteo（免金鑰）或中央氣象署；失敗即顯示「無天氣資料」中性背景 | 中央氣象署 |
| 交通時間 | 直線距離 × 道路係數估算 | Google Distance Matrix／TDX 公共運輸 |

每筆資料記錄來源網址、最後更新日期與「已確認／可能變動／待確認」狀態，資訊卡與站點詳情都會顯示。示範資料一律帶「示範資料」標記。照片以類別示意圖代替，並標示「示意圖」。

### 替換資料來源

- **景點**：設定 `DATA_PROVIDER=tdx` 與 TDX 金鑰，`src/lib/adapters/places.ts` 的 `loadFromTdx()` 會抓苗栗縣景點；營業時間文字無法可靠解析時標為「待確認」。餐飲／旅宿仍沿用示範資料，需另接來源。
- **自有資料**：依 `Place` 型別（`src/lib/types.ts`）提供 JSON，於 `loadPlaces()` 回傳即可，引擎與 UI 不需修改。
- **燈會**：直接編輯 `src/config/lantern.json`。

## 天氣、日夜與背景

- 背景依「使用者當下所在地」天氣（晴／多雲／雨／無資料）與裝置當地時間（早上 5–11、下午 11–17、夜晚 17–23、深夜 23–5）切換，共 16 組主題，集中在 `src/lib/theme.ts`。
- 背景為固定層，只改色彩與裝飾圖形；內容卡片永遠是不透明淺色底與深色字，切換主題不影響版面與按鈕位置（端對端測試驗證 16 組主題下標題對比度 > 7:1、底部選單位置不變）。
- 使用定位前先詢問；拒絕時可手動選擇所在地。天氣取不到時使用中性背景並標示。
- 雨天只在「我現在附近」與旅途中重新規劃時提高室內地點順位；規劃未來日期時不會把今天的天氣說成苗栗預報。

## 已知限制

- 示範資料的營業時間、旅宿規定與交通時間皆非即時或官方確認；正式使用前需接政府開放資料並與業者確認。
- 交通時間預設為距離估算；Google 校正與 TDX 介接已實作但未以真實金鑰驗證。
- Claude 文字整理已實作並測試降級與驗證邏輯，但本環境沒有 API 金鑰，未實際呼叫。
- 中央氣象署介接使用縣市層級 36 小時預報的第一個時段作為「目前天氣」，非測站即時觀測。
- 一趟旅程只安排同一間旅宿；3 天 2 夜換宿尚未支援。
- 大眾運輸以「公車／計程車接駁」概估，未查詢實際班次。
- 行程只存在瀏覽器 localStorage，沒有帳號或跨裝置同步。
- 未讀取競賽規範 PDF（`苗栗縣115年苗青創想家．黑客松競賽活動-實施計畫及報名簡章.pdf` 未提供）。
